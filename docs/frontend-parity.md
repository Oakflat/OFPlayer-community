# Community 界面与功能边界

Community 以主线 WinUI 的播放器界面与交互为基准，不再采用另写的极简歌曲列表。

## 保留

- 曲库来源选择、所有歌曲、收藏、最近播放、最近添加、专辑、歌手与歌单。
- 主线歌曲行、封面、搜索、筛选、排序、多选、上下文菜单、拖动排序与定位正在播放的歌曲。
- 主线播放栏、上一首/下一首、顺序/循环/随机模式、进度、音量、输出设备与歌曲详情。
- 本地定时歌词、歌词文件绑定、沉浸播放和桌面歌词胶囊。
- 主线托盘菜单、最小化到托盘、关闭行为、浅深色、封面背景及胶囊外观设置。
- 侧栏采用主线的 224/48 DIP 布局、逐帧宽度过渡、原生紧凑菜单、动态音乐图标和智能歌单分组；菜单行按身份复用，保留滚动、焦点与选中状态。
- 本地视频播放、字幕、倍速、全屏和位置保存。
- 用户配置的 WebDAV、Navidrome/Subsonic 媒体库。请求只针对用户选择的服务器；这些连接不使用 OFPlayer 账号。

## 排除

设备配对、OFPlayer 跨设备串流、handoff、Together、官方云曲库、账号登录、付款、许可证、订阅、中继服务与官方更新服务不进入 Community 的运行依赖和命令接口。主线的付费自定义背景图片入口也不提供。

必需的最小每日活跃统计保持原有 Community 规则，无账号依赖、无诊断页开关，不发送媒体内容、曲名或文件路径。

## 独立性与兼容

WinUI 页面及其纯展示逻辑保留主线结构，Community host 提供本地命令适配。Rust 目录、排序、队列和第三方媒体库代码在本仓编译。沉浸页和歌词胶囊从 `web/` 编译，不复制其他客户端的运行时或旧产物。

侧栏结构查询沿用主线的轻量曲库/歌单投影，不再为了刷新导航读取完整曲目快照；通用本地实现的对齐不引入主线的商业配额投影或授权依赖。

继续使用 `%LOCALAPPDATA%/ofplayer-community`；旧 Tauri 数据迁移只读来源并清理商业状态，已有 Community 数据不覆盖。WebView2 缓存位于 `%LOCALAPPDATA%/ofplayer-community-webview2`。主线 WinUI 的数据和安装身份不参与此次修改。

视频仍由本仓的 Windows Media 后端播放，不包含可选 FFmpeg 或 ASIO 组件。编译与合成媒体测试不代表声卡、4K/HDR、全部编码或第三方真实服务器验收。
