# OFPlayer Community 隐私说明

Community 的曲库、歌单、收藏、播放历史、歌词、字幕和媒体文件保存在本机。应用不提供账号登录、一起听、云曲库、远程串流、设备配对、远程控制或曲库训练共享。

应用会发送必需的最小每日活跃统计。字段为 UTC 日期、每天更换的随机标识、应用版本、发行渠道和平台；标识在本机生成，不依赖账号或设备硬件。应用不会把曲名、文件路径、媒体内容或本地曲库发送到活动接口。HTTP 服务在处理连接时可见来源 IP 等常规网络信息；应用请求不附加账号 Cookie。

统计接口为 `https://api.ofplayer.org/v1/telemetry/activity`。每个 UTC 日成功后不重复发送，失败有退避，并遵循服务器限流/维护响应。持续播放跨日可触发新一天统计；闲置时没有统计心跳。没有诊断页关闭项，统计失败不会阻止本地播放。

数据默认位于 `%LOCALAPPDATA%/ofplayer-community`。旧 Tauri 数据迁移只读取旧库并保留源目录，排除账号、许可、配对和远程连接凭据。新目录已有数据时不覆盖。用户可在应用退出后自行备份该目录。

Community 没有在线更新器，不自动卸载或替换已安装的 OFPlayer。
